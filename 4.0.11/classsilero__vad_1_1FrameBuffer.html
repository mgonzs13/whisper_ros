Detailed Description

Accumulates arbitrary-length audio chunks into fixed-size frames.

Audio messages from different publishers (for example an AEC node) may have a different chunk size than the frame size expected by Silero VAD. This buffer lets the node feed the model complete frames without dropping or zero-padding the tail of every message.
